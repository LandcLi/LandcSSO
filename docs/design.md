# LandcSSO 项目设计文档

## 1. 设计目标

- **一次登录，多处访问** - 用户只需登录一次即可访问所有信任的应用
- **安全性** - 防止凭证泄露、会话劫持、CSRF等攻击
- **可扩展性** - 支持海量用户和高并发
- **标准化** - 遵循开放协议标准
- **用户体验** - 减少重复登录，支持多种登录方式

## 2. 核心组件设计

### 2.1 认证中心 (Identity Provider, IdP)

- **统一认证服务** - 处理所有登录请求
- **会话管理** - 维护全局会话状态
- **令牌服务** - 颁发和验证令牌
- **用户目录** - 存储用户身份信息和凭证

### 2.2 服务提供方 (Service Provider, SP)

- **业务应用** - 需要SSO保护的各个系统
- **本地会话** - 维护应用本地会话
- **SP客户端SDK** - 集成到应用的认证模块

### 2.3 支撑服务

- **会话存储** - Redis集群存储会话数据
- **密钥管理** - 管理签名/加密密钥
- **审计日志** - 记录所有认证事件
- **监控告警** - 实时监控系统状态

## 3. 技术选型

### 3.1 后端框架

- **Go语言** - 高性能、并发友好
- **Gin框架** - 轻量级Web框架，高性能路由

### 3.2 数据存储

- **MySQL** - 存储用户信息、客户端信息等持久化数据
- **Redis** - 存储会话数据、令牌黑名单等缓存数据

### 3.3 认证协议

- **OAuth 2.0** - 授权框架
- **OpenID Connect** - 身份认证层

### 3.4 安全措施

- **JWT** - 无状态令牌
- **RSA** - 非对称加密签名
- **HTTPS** - 传输加密
- **PKCE** - 增强OAuth安全

### 3.5 日志和监控

- **LandcLogFace** - 统一日志门面
- **LandcCommonApi** - 统一API响应格式

### 4.2 核心流程

#### 4.2.1 首次登录流程

1. 用户访问应用A
2. 应用A检查本地会话，发现无会话
3. 重定向到认证中心，携带redirect_uri和state参数
4. 认证中心检查全局会话，发现无会话
5. 显示登录页面，用户输入凭证
6. 认证中心验证凭证，创建全局会话
7. 生成授权码，重定向回应用A，携带授权码和state参数
8. 应用A使用授权码向认证中心请求访问令牌
9. 认证中心验证授权码，颁发访问令牌和刷新令牌
10. 应用A使用访问令牌获取用户信息
11. 应用A创建本地会话，用户访问应用A

#### 4.2.2 访问其他应用流程

1. 用户访问应用B
2. 应用B检查本地会话，发现无会话
3. 重定向到认证中心，携带redirect_uri和state参数
4. 认证中心检查全局会话，发现有会话
5. 直接生成授权码，重定向回应用B，携带授权码和state参数
6. 应用B使用授权码向认证中心请求访问令牌
7. 认证中心验证授权码，颁发访问令牌和刷新令牌
8. 应用B使用访问令牌获取用户信息
9. 应用B创建本地会话，用户访问应用B

#### 4.2.3 登出流程

1. 用户在应用A中登出
2. 应用A清理本地会话
3. 重定向到认证中心的登出端点
4. 认证中心清理全局会话
5. 认证中心通知所有已登录的应用
6. 各应用清理本地会话
7. 重定向到认证中心登录页

## 5. 核心功能实现

### 5.1 用户认证

- **用户名/密码认证** - 标准认证方式
- **短信/邮箱验证码** - 辅助认证方式
- **第三方登录** - 集成微信、钉钉、GitHub等
- **生物识别** - 预留接口
- **扫码登录** - 预留接口

### 5.2 令牌管理

- **访问令牌** - 短期令牌，用于访问受保护资源
- **刷新令牌** - 长期令牌，用于刷新访问令牌
- **令牌验证** - 验证令牌的有效性
- **令牌撤销** - 主动撤销令牌
- **令牌黑名单** - 存储已撤销的令牌

### 5.3 会话管理

- **全局会话** - 认证中心维护的会话
- **本地会话** - 各应用维护的会话
- **会话过期** - 可配置的会话超时
- **会话续期** - 活跃会话自动续期
- **并发会话** - 限制同一用户的并发会话数

### 5.4 客户端管理

- **客户端注册** - 注册服务提供方应用
- **客户端密钥** - 生成和管理客户端密钥
- **重定向URI** - 验证重定向URI
- **权限范围** - 管理客户端权限范围

### 5.5 审计日志

- **认证事件** - 记录登录、登出、令牌颁发等事件
- **操作事件** - 记录用户管理、客户端管理等操作
- **安全事件** - 记录异常登录、令牌撤销等安全事件
- **查询统计** - 支持按时间、用户、事件类型等查询

### 5.6 监控告警

- **认证指标** - 认证成功率、平均认证时长等
- **系统指标** - CPU、内存、网络等系统资源使用情况
- **异常检测** - 检测异常登录、令牌滥用等
- **告警通知** - 邮件、短信、Webhook等通知方式

## 6. 安全设计

### 6.1 传输安全

- **强制HTTPS** - 所有通信使用HTTPS
- **HSTS** - HTTP Strict Transport Security
- **TLS配置** - 配置安全的TLS版本和密码套件

### 6.2 认证安全

- **密码哈希** - 使用bcrypt加密存储密码
- **多因素认证** - 支持双因素认证
- **防暴力破解** - 限制登录尝试次数
- **验证码** - 登录失败多次后要求输入验证码

### 6.3 令牌安全

- **非对称加密** - 使用RSA签名JWT
- **短期令牌** - 访问令牌有效期短
- **令牌绑定** - 绑定客户端IP、设备指纹等
- **令牌撤销** - 支持主动撤销令牌

### 6.4 会话安全

- **会话ID随机** - 使用安全的随机数生成会话ID
- **会话过期** - 可配置的会话超时
- **会话绑定** - 绑定客户端IP、User-Agent等
- **并发限制** - 限制同一用户的并发会话数

### 6.5 防CSRF攻击

- **State参数** - OAuth授权流程中使用state参数
- **CSRF Token** - 表单提交时验证CSRF Token
- **SameSite Cookie** - 设置Cookie的SameSite属性

### 6.6 防XSS攻击

- **输入验证** - 验证所有用户输入
- **输出编码** - 编码所有输出
- **Content-Security-Policy** - 配置内容安全策略
